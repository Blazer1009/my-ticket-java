# my-ticket-java

Turn the **Light 0** into a ticket! Simply use an anvil to rename the item to **“Ticket”**, and it will transform into a custom ticket design.

The **final release for Minecraft 26.2** is now available!

This simple Minecraft Java resource pack replaces the Light 0 texture with a ticket design featuring an orange color scheme and reflective details. It’s perfect for **servers, events, custom maps, and other creative projects**.

### Features

* Replaces the Light 0 texture with a custom ticket design.
* Rename the item to **“Ticket”** using an anvil to activate the ticket texture.
* Orange ticket design with reflective details.
* Great for servers, events, custom maps, and more.
* Includes a **No Extra Modifications** version for a simple experience.
* The **Extra Modifications** version adds even more fun features, including a custom title logo and additional changes.

## Installation

1. Download the version you want from the release page.
2. Open Minecraft and go to **Options → Resource Packs**.
3. Click **Open Pack Folder**.
4. Move the downloaded `.zip` file into the resource packs folder.
5. **Do not extract the `.zip` file** unless required.
6. Return to Minecraft and enable the resource pack.
7. Use an anvil to rename a **Light 0** to **“Ticket”** and enjoy your new ticket!
